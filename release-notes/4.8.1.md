## What's Changed

**Small updates, even after a reinstall:** on Windows, uninstalling GazBoard and installing it again by hand could leave an old file behind that made the next update fetch the changed parts, fail its final check, and then download the whole 102 MB anyway. GazBoard now checks that file before every update and ignores it if it no longer fits, so only what changed comes down. Macs get the same check on the copy they build updates from. Linux AppImages already compare against the actual file on disk, so they were never affected.

**updater.log:** every update on Windows, Mac and Linux now writes a short log beside GazBoard's settings, so if an update ever downloads everything instead of just the changes, the reason is written down.
