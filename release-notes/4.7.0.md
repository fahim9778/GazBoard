## What's Changed

**Choose where boards are kept (desktop):** Settings, Storage, Change folder. Point two computers at the same folder and both see the same boards. Thanks @ParallaX07 for building it and @CuzImBisonratte for asking for it.

**Android safe copy:** keep a copy of your boards in a folder of your choice, so they survive an uninstall. After reinstalling, Bring boards back returns them. Open folder shows them in the Files app. No storage permission needed.

**Drag and drop everywhere:** drop PDFs, images and .gazboard files into the web version, or drag them in from Files or Gallery in Android split screen.

**Smaller updates on Mac and Linux:** the AppImage now updates itself, and both download only what changed.

**Play Store ready:** copies installed from Google Play or F-Droid leave updates to the store.

**German:** Deutsch is now in Settings, Language. Thanks @CuzImBisonratte.

**Fixes:** Change folder now opens in the folder you're using instead of Documents, web imports read file names with spaces correctly, and every release is checked to make sure its update files actually arrived.
