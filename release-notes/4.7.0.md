## What's Changed

**Choose where your boards are kept (Windows, Mac, Linux):** Settings, Storage, Change folder. Pick any folder and GazBoard keeps everything in a GazBoard folder inside it: the boards, their pictures and your My boards folders. It copies your boards across and checks every file arrived before switching, then offers to move the old copies to the Trash. Point a second computer at the same folder and it finds the same boards, filed in the same folders. If the folder ever goes missing, an unplugged drive say, GazBoard says so and keeps working from the usual place until it is back. Reset to default puts everything back. Thanks to @ParallaX07, who built the first version of this, and to @CuzImBisonratte for asking for it.

**Your boards survive uninstalling on Android:** turn on Keep a safe copy in a folder, in My boards or Settings, and pick a folder on your phone. Every board, picture and My boards folder is copied there as you work, and the folder stays when GazBoard is uninstalled. After installing again, Bring boards back from a folder returns them, in their folders. No storage permission is asked for: Android's own folder picker hands over that one folder and nothing else.

**Drag and drop everywhere:** drop a PDF onto the board in the web version and it comes in page by page, and a dropped .gazboard file opens. On an Android tablet or phone in split screen, drag photos, PDFs and Office files across from Files or Gallery: pictures land under your finger.

**Smaller updates on Mac and Linux:** the AppImage now updates itself from inside GazBoard and downloads only the parts that changed, then restarts into the new version under the same file name, so your menu entry keeps working. A Mac that updated itself once now builds the next update from the copy it kept and fetches only what changed; the first update after installing from the disk image is still a full download.

**Play Store ready:** a copy installed from Google Play or F-Droid never looks at GitHub and never offers a download, because the store keeps it up to date. Copies downloaded from GitHub keep their update notices as before.

**GazBoard speaks German:** Deutsch is now in Settings, Language, and a German computer picks it up by itself. Thanks to @CuzImBisonratte for the whole translation.

**Fixes:** file names with spaces now read properly when importing in the web version, and the release now checks that every file the in-app updaters need actually reached the release page.
